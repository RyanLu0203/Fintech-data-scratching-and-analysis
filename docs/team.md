# Team and deliverables

This is a group course project. Repository ownership alone does not establish
who implemented each module. The available materials do not verify a named
contribution table, so assignments remain to be confirmed by the original team.

| Workstream | Contribution to record with team confirmation |
|---|---|
| Data | providers, collection, caching, timestamp and coverage checks |
| NLP | preprocessing, lexicon/LR/FinBERT, peer labels and benchmark |
| RL | handwritten DQN, environment, state/action exploration |
| Integration | storage, batch orchestration, dashboard and traceability |
| Analysis and reporting | comparisons, interpretation, report and presentation |

Existing deliverables include `reports/final_report.md`,
`reports/presentation_outline.md`, `reports/live_demo_script.md`, two original
notebooks, and the course specification in `docs/Project_Guidelines.docx`.
The original report is preserved with a revision notice and a separate
current-method addendum. Public team details should contain confirmed names
and contributions; student IDs and private contact details are unnecessary.
